# Domain Manager Documentation

This directory contains comprehensive documentation for the Domain Manager project.

## Directory Structure

- `requirements/` - Requirements documentation
  - `srs.md` - Software Requirements Specification
  - `diagrams/` - Requirements-related diagrams (use case, activity diagrams, etc.)

- `design/` - Design documentation
  - `sdd.md` - Software Design Document
  - `architecture.md` - Architecture documentation
  - `diagrams/` - Design-related diagrams (class diagrams, sequence diagrams, etc.)

- `assets/` - Documentation assets
  - `images/` - Images used in documentation
  - `diagrams/` - Source files for diagrams

## Contributing to Documentation

1. Place new documentation in the appropriate directory
2. Use Markdown format for documentation files
3. Store diagrams source files in `assets/diagrams/`
4. Reference images using relative paths
5. Update this README when adding new documentation

## Guidelines

- Use clear and descriptive file names
- Include date and version information in documents
- Keep diagrams up-to-date with code
- Reference requirements in design documents
- Use consistent formatting across documents
